# Video Embed

This page shows a simple YouTube embed inside a note.

<div style="position:relative; padding-bottom:56.25%; height:0; overflow:hidden; border-radius:1rem;">
  <iframe
    src="https://www.youtube.com/embed/-eG5hmMVbms"
    title="Sample YouTube video"
    frameborder="0"
    allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture"
    allowfullscreen
    style="position:absolute; top:0; left:0; width:100%; height:100%;"
  ></iframe>
</div>
<br/>
If the embed does not render, try the same URL in a normal browser tab.
